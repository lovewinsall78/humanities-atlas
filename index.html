콘텐츠 확장·관리

영상 추가

공개 영상의 제목과 주소를 입력합니다. 추가된 영상은 현재 브라우저에 저장됩니다. 전체 이용자에게 공개하려면 GitHub의 videos.json에 반영해야 합니다.

목록 가져오기·내보내기

videos.json 형식으로 영상 목록을 확장할 수 있습니다. 중복은 YouTube 영상 ID로 구분합니다.

확장 설계

① YouTube Data API로 채널 목록 수집 → ② 영상별 분야 분류 → ③ 교재 본문·출처·퀴즈 작성 → ④ 사실 검수 → ⑤ GitHub에 JSON 반영.

자동 수집에는 API 키와 서버 또는 GitHub Actions가 필요합니다. 검수되지 않은 영상은 교육용 본문으로 공개하지 않습니다.
